# backstage-aggregator

This is the Backstage instance that aggregates the **Aurora Logistics**
reference catalog: a hypothetical enterprise used to demonstrate Backstage
integrating with REST APIs, Protobuf/gRPC APIs, A2A agents, MCP tool
servers, Kafka messaging, databases, observability tooling, and
backend/frontend apps across a dozen satellite repositories.

See [ADR-0001](adrs/0001-satellite-repository-topology.md) for the full
repo topology and design rationale.
