# Architecture Decision Records

This directory records the architecture decisions for this repository, which
acts as the **Backstage aggregator** for the hypothetical enterprise used
throughout this project's examples (see [ADR-0001](0001-satellite-repository-topology.md)
for the scenario). Each ADR captures a decision, the context that drove it,
and its consequences, following the lightweight [MADR](https://adr.github.io/madr/)
style.

| ADR | Title | Status |
| --- | --- | --- |
| [0001](0001-satellite-repository-topology.md) | Satellite repository topology for the reference enterprise catalog | Accepted |

## Adding a new ADR

1. Copy the highest-numbered file as a starting point.
2. Increment the number, give it a short kebab-case title.
3. Fill in Context / Decision / Consequences / Alternatives.
4. Add a row to the table above and open a PR.
